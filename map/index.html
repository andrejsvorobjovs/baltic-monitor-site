Recent Baltic activity, mapped

The same AIS ship, military ADS-B aircraft, GPS-jamming, and NASA FIRMS thermal-hotspot data this project already fetches every scan and shares with its owner over Telegram — plotted here for anyone to see, with a static reference layer of the region's real undersea cables and pipelines underneath.

This is not live tracking, and nothing on this map is itself an alert. It's a rolling window of recent scan snapshots (this project scans roughly every 4 hours), not a continuous feed.

AIS (ship) and ADS-B (aircraft) positions are self-declared by each vessel/aircraft's own transponder — real-world identifiers, but unverified and spoofable, the same as any AIS/ADS-B data anyone can already see for free on flightradar24 or marinetraffic. GPS-jamming cells (GPSJam) and thermal hotspots (NASA FIRMS) are raw, unconfirmed, informational data — a jamming cell doesn't confirm an actual jammer, and a thermal detection is triggered just as readily by a wildfire or agricultural burn as by anything else. None of this feeds this project's own WATCH/WARN scoring on its own; read it alongside real context, never in isolation.

How to read this map

🚢 AIS ships

Positions from a short live listen window on aisstream.io each scan — whichever vessels happened to report during that window, not exhaustive coverage. A vessel showing as Military/Law Enforcement/Noncombatant is reading its own transponder's self-declared type code, not a verified identity.

✈️ Military aircraft

ADS-B positions from adsb.lol's free military-flagged feed. Only shows aircraft actively broadcasting — many military flights fly with it off, spoofed, or unavailable, so this is a partial picture, never exhaustive coverage.

🛰️ GPS-jamming cells

GPSJam's own "High interference" H3 cells (crowdsourced from aircraft-reported GPS accuracy), plotted at each cell's center. Correlates with, but doesn't confirm, actual jamming — and this region has chronic background jamming even on an ordinary day.

🔥 Thermal hotspots

NASA FIRMS (VIIRS) satellite heat-signature detections. Raw thermal data, not confirmed military or security activity — wildfires, agricultural burning, and industrial flares all trigger a detection just as readily as anything else would.

Undersea cables & pipelines

A static reference layer, not scan data — real submarine telecommunications cable routes and landing points in the Baltic region, from TeleGeography's Submarine Cable Map (© TeleGeography, CC BY-NC-SA 3.0), trimmed to this region and bundled with the site rather than fetched live. Shown for context — the kind of infrastructure that's occasionally been damaged in this region — not because anything plotted above it is connected to it.

Not an official warning system

If you're worried about an actual emergency, always check your own country's official channels first: Estonia — kriis.ee · Latvia — vugd.gov.lv · Lithuania — lrv.lt.
